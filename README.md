## 🔧 Customization

### Change Colors
Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6c5ce7;
    --secondary-color: #a29bfe;
    --accent-color: #fd79a8;
    /* ... other colors ... */
}
```

### Add Portfolio Items
Add new items to the portfolio section in `index.html`:

```html
<div class="portfolio-item [category]">
    <img src="your-image.jpg" alt="Description">
    <div class="portfolio-info">
        <h3>Project Title</h3>
        <p>Project Description</p>
    </div>
</div>
```

### Update Contact Info
Replace the placeholder contact details with your actual information in the Contact section.
